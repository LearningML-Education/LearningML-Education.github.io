**El laboratorio de Machine Learning (Playground) de LearningML está pensado para que el alumnado entienda, de forma visual y práctica, cómo aprende un algoritmo.** Y para el profesorado es una herramienta perfecta para pasar de la explicación teórica a la experimentación en clase en pocos minutos.

Se accede desde el **modo avanzado** de dos formas: desde la opción **Laboratorio de ML** del menú superior o desde el enlace **"Aprende sobre ... en el laboratorio de ML"** en la pestaña **Aprender**.

<img src="/images/posts/el-laboratorio-de-machine-learning-de-learningml/playground.png" alt="Laboratorio de ML en LearningML" style="display:block;width:100%;max-width:760px;height:auto;margin:0 auto;" />

Una vez dentro, el flujo es muy simple:

- Crear el conjunto de datos automáticamente o dibujarlo a mano.
- Elegir el patrón de datos (nubes, círculos o espirales), el número de clases, el número de muestras y el ruido.
- Seleccionar algoritmo: **Red neuronal, KNN o Naive Bayes**.
- Ajustar hiperparámetros y pulsar **"Construir modelo de ML"**.

En la gráfica se ven los puntos y las **zonas de decisión** del modelo, lo que facilita muchísimo explicar por qué un algoritmo clasifica como clasifica. Además, con **Red neuronal** se muestra una superposición con la evolución de **loss, error y accuracy**, ideal para analizar si el aprendizaje mejora de verdad.

Y, para apoyar la explicación en el aula, el botón **"La teoría sobre este algoritmo"** abre una guía conceptual del algoritmo seleccionado dentro del propio editor.

**En resumen:** el laboratorio de ML convierte el modo avanzado de LearningML en un espacio de exploración guiada, muy útil para diseñar actividades donde el alumnado compare algoritmos, pruebe hipótesis y desarrolle intuición sobre el aprendizaje automático.

Si todavía no lo has probado en clase, este es un buen momento: **abre el laboratorio, cambia parámetros y deja que tus estudiantes vean el Machine Learning en acción.**
