🌟 En este video vamos a descubrir una **nueva funcionalidad de la versión 2 de LearningML** 🤩

Cuando guardamos el proyecto de Scratch, el modelo de Machine Learning se guarda dentro del archivo sb3 🚀⁣⁣

###### En el editor de modelos

✅ Subimos datos para entrenar⁣  
✅ Generamos el modelo de Machine Learning  
✅ Lo probamos y… funciona!!!⁣

###### En Scratch

✅ Creamos nuestra aplicación con Scratch  
✅ Guardamos el proyecto

En versiones anteriores, cuando abandonábamos Scratch, si queríamos volver más tarde, debíamos comenzar con todos los pasos nuevamente…  
📌**¡¡¡Ahora, Scratch guarda el programa!!!** No necesitamos volver a generar el modelo desde LearningML
