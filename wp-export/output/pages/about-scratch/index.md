**[Scratch](https://scratch.mit.edu/about) is an educational platform for learning to program.** It is a project of the Lifelong Kindergarten Group of the MIT Media Lab and is distributed under a free license.

**The LearningML programming platform is a modified version of Scratch** to which we have added the necessary blocks to use the Machine Learning models that we built with the editor.
